# Codeforces Practice Repository

This repository contains a structured collection of solutions to Codeforces problems, organized by difficulty and practice days.

## Structure

- **CP31/**: Main directory containing all solutions.
  - **Difficulty Folders (e.g., 800/, 900/, ..., 1900/):**
    - Each folder contains Java solutions to problems of the corresponding Codeforces difficulty rating.
    - Example: `800/A_Ambitious_Kid.java` is a solution to an 800-rated problem.
  - **Day Folders (e.g., Day1/, Day10/, ...):**
    - Each folder contains solutions solved on a specific day, useful for tracking daily progress.
    - Example: `Day10/A.java` is a solution solved on Day 10.

## How to Use

- Browse by difficulty to find solutions for specific rating levels.
- Browse by day to review daily practice and progress.
- All solutions are written in Java.
